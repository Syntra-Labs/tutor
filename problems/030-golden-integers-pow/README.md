# 030: $\mathbb{Z}[\phi]$ Binary Exponentiation & Fibonacci Identity

## Problem Statement

By Dirichlet's Unit Theorem, the unit group of $\mathbb{Z}[\phi]$ is generated by $\pm \phi^n$ for $n \in \mathbb{Z}$. Moreover, integer powers of $\phi = (0, 1)$ in $\mathbb{Z}[\phi]$ encode the two-sided Fibonacci sequence $F_n$ directly in their coordinates.

Implement `ZPhi::pow(int64_t n) const` using $O(\log |n|)$ binary exponentiation for both non-negative exponents $n \ge 0$ and negative exponents $n < 0$ (for units where `inv()` exists). Also implement `fibonacci_pair(int64_t n)` returning $\phi^n = F_{n-1} + F_n\phi$.

## Mathematical Law / Invariant

For all $n \in \mathbb{Z}$ (with $F_0 = 0, F_1 = 1$, and $F_{-k} = (-1)^{k+1} F_k$):

$$\phi^n = F_{n-1} + F_n \phi = (F_{n-1}, F_n) \in \mathbb{Z}[\phi]$$

Taking the algebraic norm on both sides yields **Cassini's Identity** automatically:

$$N(\phi^n) = F_{n-1}^2 + F_{n-1} F_n - F_n^2 = (N(\phi))^n = (-1)^n$$

And for all $m, n \in \mathbb{Z}$:

$$\phi^m \cdot \phi^n = \phi^{m+n}, \qquad \phi^n \cdot \phi^{-n} = (1, 0)$$

- **Space:** $O(1)$.
