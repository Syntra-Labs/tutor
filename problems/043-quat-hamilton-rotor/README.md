# 043: Non-Commutative Hamilton Product & Axis-Angle Rotor

## Problem Statement

The quaternion algebra $\mathbb{H}$ is an associative, non-commutative normed division algebra generated by $i^2 = j^2 = k^2 = ijk = -1$. In `TreeRotorOperator`, non-commutative Hamilton multiplication and sandwich conjugation $r \otimes q \otimes \bar{r}$ encode asymmetric left vs. right tree branches without losing norm stability.

## Mathematical Law / Invariant

1. **Hamilton Product ($p \otimes q$):**
   $$\begin{aligned}
   (p \otimes q)_w &= p_w q_w - p_x q_x - p_y q_y - p_z q_z \\
   (p \otimes q)_x &= p_w q_x + p_x q_w + p_y q_z - p_z q_y \\
   (p \otimes q)_y &= p_w q_y - p_x q_z + p_y q_w + p_z q_x \\
   (p \otimes q)_z &= p_w q_z + p_x q_y - p_y q_x + p_z q_w
   \end{aligned}$$
2. **Norm Multiplicativity:** $\|p \otimes q\|_2 = \|p\|_2 \|q\|_2$, and $\overline{p \otimes q} = \bar{q} \otimes \bar{p}$.
3. **Axis-Angle Rotor Construction:** Given angle $\theta \in \mathbb{R}$ and axis $\mathbf{u} = (u_x, u_y, u_z)$, if $\|\mathbf{u}\|_2 < 10^{-12}$ return $(1, 0, 0, 0)$, else:
   $$r(\theta, \mathbf{u}) = \left(\cos\frac{\theta}{2},\; \frac{\sin(\theta/2)}{\|\mathbf{u}\|_2}(u_x, u_y, u_z)\right)$$
4. **Sandwich Action:** `q.rotate(r)` computes $r \otimes q \otimes \bar{r}$.

```cpp
Quat Quat::mul(const Quat& q) const;
Quat Quat::rotate(const Quat& r) const;

```

## Complexity Target

- **Time:** $O(1)$ (16 multiplies + 12 adds per Hamilton product).
- **Space:** $O(1)$.
